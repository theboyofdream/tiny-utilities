# Pin2Top Design (pin-to-top.c)

- **CLI** (`--border-width N`, `--max-windows N`, `--window-selection true|false`): optional; missing/unknown flags, missing values, and non-integers are ignored and fall back to defaults; out-of-range values are clamped. Ranges: border 1–20, max-windows 1–10. Parsed declaratively via `TinyCLI_ParseCommandLine` (`src/common/tiny_cli.h`) with fallback support for `--flag=val`. `--window-selection` defaults to `true` (opens interactive window picker on launch); set `--window-selection false` (or `--no-picker` / `--active` / `--foreground`) to immediately pin the foreground window without a picker.
- **Config** struct: `{ int borderWidth; int maxWindows; bool windowSelection; }`. Tunable defaults are `#define`s at the top of `pin-to-top.c`: `DEFAULT_BORDER_WIDTH` (2), `DEFAULT_MAX_WINDOWS` (1), `DEFAULT_BORDER_COLOR` (RGB(0,120,215)), plus range bounds `BORDER_MIN/MAX` (1/20) and `MAXWINDOWS_MIN/MAX` (1/10).
- **Border color**: default is `DEFAULT_BORDER_COLOR`; at first-launch `g_borderColor = GetWallpaperDominantColorThief()` (`src/common/color-thief-algorithm.h`, DWM accent API with MMCQ fallback, GDI-only) queries the system accent color or MMCQ quantization. Falls back to default if sampling fails.
- **Border accuracy**: overlay windows are positioned from `GetFrameRect`, which prefers `DwmGetWindowAttribute(DWMWA_EXTENDED_FRAME_BOUNDS)` (`dwmapi` loaded via `LoadLibrary`/`GetProcAddress`) and falls back to `GetWindowRect` when DWM is unavailable.
- **State**: array `g_pinned[MAX_PIN_SLOTS]` of `{HWND target; HWND overlay; RECT lastRect;}`.
- **First launch**: `TinyDPI_EnablePerMonitorAwareness()` → `TinyIPC_AcquireOrToggle()` (`src/common/tiny_ipc.h`) creates mutex and auto-reset event → samples wallpaper accent color → opens interactive picker (or pins foreground in non-picker mode) → tracks pinned windows. **Second launch**: signals toggle via `TinyIPC_AcquireOrToggle()` → exits immediately (`0`).
- **Toggle logic**: on event, if foreground window is already tracked → unpins it and destroys its overlay (exits if 0 pinned windows remain). If foreground window is not tracked: in picker mode, shows interactive window picker overlay; in non-picker mode, pins foreground window (unpinning oldest if `maxWindows` reached).
- **Interactive Picker overlay**: full desktop dimming with active-monitor-centered prompt. Hovering over an unpinned window highlights blue (`[ Click ] Pin Window`); hovering over an already pinned window highlights orange (`[ Click ] Unpin Window`). Ignores cloaked (`DWMWA_CLOAKED`), shell/desktop, and tool windows (`WS_EX_TOOLWINDOW`). Overlay destruction cleanly ends modal loop without posting `WM_QUIT`.
- **Pin/unpin**: `SetWindowPos(target, HWND_TOPMOST / HWND_NOTOPMOST, ..., SWP_NOMOVE|SWP_NOSIZE)`. Pinned target window is focused to foreground upon selection.
- **Tracking loop** (16 ms): `!IsWindow(target)` → drop entry silently (exits process when `pinnedCount == 0`); `IsIconic` → hide overlay; else compare `GetFrameRect` to `lastRect`, resize/reposition overlay and invalidate for repaint, maintaining topmost Z-order above active target.
- **Pinned-window lifecycle edge case**: window destroyed while pinned → silently removed (nothing to unpin). Overlay destroyed in every removal path.
- **Exit path**: loop breaks → unpin all remaining + destroy overlays → close event handle → `return 0`.
