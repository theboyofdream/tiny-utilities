# Capture Tool Design (capture.c)

- **CLI**: `--fullscreen`, `--window`, `--snip`, `--draw`, `--draw-toolbar`, `--font-size N`, `--format png|bmp`, `--clipboard`, `--save <path>`.
- **Interactive No-Args Flow**: When launched without CLI arguments, displays a full-screen translucent dimmed desktop backdrop with mode selection text centered as a group both vertically and horizontally on screen with prominent 22px text and clear ~14px hint text (without an enclosing window card). Text lines are left-aligned in fixed sub-rectangles (`1. Snip (Region)`, `2. Window`, `3. Full Screen`) with zero horizontal text shifting when hovered, and the `>` pointer prefix rendered independently in `accentBlue`. Uses a single unified overlay window across all stages (Selector -> Snip / Window -> Doodle Canvas) for 100% zero flickering. Upon selecting a choice, transitions seamlessly inside the same window -> doodle annotation overlay with floating toolbar -> upon pressing `Enter` ("Done"), clicking `Save`, or pressing `S`, displays a native Windows Save File Dialog (`GetSaveFileNameW`) to save the PNG image, and also copies the captured image to the Windows Clipboard.
- **Modes**: Fullscreen desktop capture, interactive window-picker overlay (`--window` with zero-jank hover highlight, DWM frame bounds detection, click/Enter selection, and Esc/right-click cancel), or interactive rubber-band region selection overlay (`--snip` with rich ~49% dark translucent background dimming).
- **Doodle Annotation**: Frameless top-level overlay (`WS_POPUP | WS_EX_TOPMOST | WS_EX_TOOLWINDOW`) preserving the translucent dimmed desktop background around the captured snip/window with 100% crisp focus on the active canvas. Includes floating toolbar (`Space` toggles visibility; single-key color/brush shortcuts `R`, `Y`, `B`, `G`, `K`, `W`, `2`, `4`, `8`, `1`, `Z`, `X`, `C`, `S`, `Enter`, `Esc`). In draw mode, pressing `Enter`, clicking `Done`/`Save`, or pressing `S` opens the native Windows Save File Dialog to save PNG if no `--save` path was passed on CLI (or directly saves to disk if `--save` was passed). Pressing `C` or clicking "Copy & Exit" copies to clipboard and exits directly.
- **Output**: Writes PNG or BMP file and/or places `CF_BITMAP` on the Windows Clipboard with mode-specific filenames (`snip_YYYYMMDD_HHMMSS.<ext>`, `capture_YYYYMMDD_HHMMSS.<ext>`, or `<appname>-<title>_YYYYMMDD_HHMMSS.<ext>`).
- **IPC Single Instance**: `Global\TinyCaptureMutex` and `Global\TinyCaptureEvent` toggle cancel support.
